# {project_name} — Vocabulary

Canonical terminology. These definitions override general-knowledge defaults when
producing work. Never sealed; the seal convention does not apply. Entries are never
removed — mark obsolete terms `[deprecated]` and name the replacement.

A branch's vocabulary overrides its parent's. **On conflict, flag it — never
resolve silently.**

**Language.** This file follows the domain's own language, not the English-only
rule that governs `_memory/`. A term's exact form is the point of recording it.

## Markers

| Marker | Meaning |
|---|---|
| `[confirmed]` | The user decided it. **The agent may never assign this marker.** |
| `[provisional]` | Direction given, details fluid |
| `[proposed]` | Agent's inference. Not canon until the user approves it |
| `[open]` | Needs discussion. Flag any draft that depends on it |
| `[deprecated]` | Replaced; successor named alongside |
